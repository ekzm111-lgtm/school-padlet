# 🏫 스쿨패들 (SchoolPad) - 학교용 실시간 협업 담벼락

선생님과 학생이 함께 만드는 실시간 온라인 협업 보드 플랫폼입니다. (패들렛 Padlet 클론)

## ✨ 핵심 기능
- **수업 보드 생성 및 테마 선택**: 그리드, 칸반(모둠별 열), 타임라인(피드) 레이아웃 및 칠판, 코르크보드, 맑은하늘 등 학교 맞춤 테마
- **포스트잇/과제 카드 작성**: 텍스트, 이미지 첨부, 링크 첨부, 포스트잇 색상 선택
- **실시간 소통 & 공감**: 카드별 공감 반응(👍 좋아요, ❤️ 감동, 💡 좋은 생각), 댓글 달기, Confetti 파티클 효과
- **학생 간편 참여**: 6자리 참여 PIN 코드 또는 QR 코드로 비로그인 즉시 입장
- **Google(Gmail) 계정 가입 & 자동 가입 정책**:
  - 기본값으로 가입 즉시 승인되는 **자동 가입 모드** 제공
  - 관리자 설정에서 **수동 승인제(가입 요청 후 승인)**로 원클릭 전환 가능
- **관리자 센터 (`/admin`)**:
  - 신규 가입 대기자 명단 확인 및 일괄/개별 승인 및 반려
  - 전체 회원(교사/학생/관리자) 권한 변경 및 모니터링
  - 개설된 수업 보드 총괄 관리
- **수업 종료 후 보드 잠금(Lock)**: 교사/관리자가 클릭 한 번으로 읽기 전용 전환
- **PDF 및 인쇄 내보내기**: 수업 결과물을 깔끔하게 A4 인쇄 또는 PDF 저장

## 🚀 Vercel 배포 방법
1. GitHub에 새 저장소(`school-padlet`)를 생성하고 본 프로젝트 코드를 푸시합니다.
2. [Vercel](https://vercel.com)에 로그인 후 `Add New...` > `Project`를 누릅니다.
3. GitHub의 `school-padlet` 저장소를 Import 한 뒤 `Deploy` 버튼을 누르면 1분 만에 전 세계에 무료 배포됩니다!
